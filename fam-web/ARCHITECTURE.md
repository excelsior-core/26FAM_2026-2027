# FAM — решения перед реализацией

Новая самостоятельная реализация. Storage доступен только для чтения. Разработка и экспорт находятся в fam-web; старый репозиторий и его история не используются.

Оболочка: нативные ES modules, CSS и локальные библиотеки. Node.js 22+ обслуживает только loopback и локальную панель. Публичная версия — статическая папка export, без backend. Все URL относительные, просмотр через query/hash, пригоден для /repository/.

Актуальная визуальная система после уточнения пользователя: античная оранжерея, старый мрамор, тёмная зелень, потемневшее золото, архитектурный фон и золотой тессеракт. Cormorant Garamond / Manrope. Темы: ночной сад, светлый мрамор, старый пергамент. Единственная математическая сцена — проекция тессеракта с золотыми рёбрами, отражениями и свечением. Движение адаптируется к размеру экрана и reduced-motion.

AES-256-GCM, 12-byte random nonce, AAD из версии/назначения/ID. Коды: случайный ID + 256-bit секрет, PBKDF2 SHA-256 не менее 600000 итераций с измерением времени. Эпохи и wrapping keys хранятся в Windows DPAPI CurrentUser, вне export. Ротация сохраняет ключи прошлых эпох для действующих пользователей. Старые ключи и скачанные материалы отозвать невозможно.

Каталог, индексы, оригиналы и приватные ресурсы — отдельные зашифрованные объекты. Сборка allowlist, инкрементальный cache по hash + epoch. Полнотекстовые индексы разделены по дисциплинам; Worker ищет по всем частям с прогрессом. Python pypdf извлекает текст PDF; сканы отмечаются как требующие локального OCR.

HTML просматривается как производная копия в sandbox allow-scripts, без allow-same-origin. CSP, локальные зависимости, защищённая отдельная вкладка, оригинал скачивается без изменений. PDF.js загружается по требованию. Расшифрованные материалы и ключи не пишутся в браузерное постоянное хранилище.

В рамках текущего запроса никакой публикации или операций записи на GitHub. publish.bat выполняет dry-run. Реальный deploy потребует отдельной команды пользователя.
