# FAM — локальная библиотека

Новая реализация студенческой библиотеки ФПМ НИУ ВШЭ, Нижний Новгород. Исходные материалы находятся в соседней папке `Storage` и используются только для чтения. Старая реализация и Git-история не использованы и не восстановлены.

## Открыть сайт

Из корня проекта запустите `start-local.bat`. Адрес: **http://127.0.0.1:4173/**. Для просмотра на этом компьютере нажмите **«Вход владельца · локальный просмотр»**. Эта кнопка появляется только при доступном локальном API; в статической публикации её нет.

`start-admin.bat` открывает **http://127.0.0.1:4173/admin**. Панель позволяет сканировать материалы, редактировать метаданные, задавать модули, создавать персональные коды, отключать их, пересобирать экспорт и сохранять защищённую резервную копию.

`watch.bat` включает наблюдение за папкой с задержкой до завершения записи. Изменения обновляют только локальный экспорт.

`publish.bat` сейчас выполняет **только локальную сборку / dry-run**. По прямому запросу пользователя публикация на GitHub отключена. Никакие push, commit или изменения удалённого репозитория не выполняются.

Нужны Node.js 22+ и Python 3 с `pypdf`. npm и сборщик не требуются. При отсутствии `pypdf`: `python -m pip install pypdf`. Все браузерные библиотеки и шрифты закреплены и находятся в `vendor` с лицензиями.

## Разработка

Из папки `fam-web`:

```text
node scripts/server.mjs
node scripts/build.mjs
node --test tests/core.test.mjs
```

Сервер слушает только `127.0.0.1`. Если порт 4173 занят, можно задать переменную `FAM_PORT`; bat-файлы используют 4173. Процесс, запущенный bat-файлом, работает в фоне. Его PID — `.local/server.pid`, журналы — `.local/server.log` и `.local/server-error.log`. Останавливайте именно этот Node-процесс через Диспетчер задач; не завершайте все процессы Node на компьютере.

Сервер читает `src` и `public` непосредственно: после правки обновите страницу. Для актуализации статического экспорта выполните сборку. `export` — единственная папка будущей публикации. Корень проекта, `Storage`, `.local`, `scripts`, `tests` и исходная `.git` туда не входят.

Основные файлы:

- `src/app.js` — вход, каталог, фильтры, темы, поиск.
- `src/antiquity.css` — актуальное художественное оформление: архитектурный фон, антиква, золото и адаптивная композиция. `src/style.css` содержит базовую структуру компонентов.
- `src/scene.js` — золотой тессеракт Three.js с отражениями, светящимися рёбрами и вершинами; ручное отключение движения, reduced motion, ограничение pixel ratio и фоновой анимации.
- `src/reader.js` — sandbox-просмотр HTML, PDF.js, скачивание и отдельная вкладка.
- `scripts/library.mjs` — сканирование, разделённые индексы и зашифрованная сборка.
- `scripts/vault.mjs` — локальное хранилище Windows DPAPI.

## Дизайн

Концепция переработана по референсам пользователя: античная оранжерея, старый мрамор, потемневшее золото, зелень, естественный свет. Композиция состоит из архитектурного фона, надписи FAM и одного золотого тессеракта. Шрифты — Cormorant Garamond с настоящим курсивом и Manrope, оба с кириллицей.

Три темы: «Ночной сад», «Светлый мрамор», «Старый пергамент». Первый визит использует системную тему, затем сохраняется выбор. Тема приложения не изменяет авторское оформление исходных лекций.

Изображения созданы встроенным ImageGen и сохранены в `public/assets/conservatory.png` и `public/assets/geometry-muse.png`. Полные промпты и режим генерации записаны в `DESIGN-ASSETS.json`. Это художественные изображения, а не фотографии реального университета.

## Каталог и поиск

Текущая библиотека: 35 записей, 32 HTML и 36 PDF. HTML/PDF в одной папке предлагаются как вложения одной записи. Самостоятельные PDF также доступны. Сложные связи по номерам не строятся. Остальные материалы автоматически не публикуются, кроме локальных изображений, на которые прямо ссылается HTML.

Предложенные метаданные видны в локальной панели и требуют проверки владельцем. Курс — 1, учебный год — 2026/27. Официальные интервалы модулей не придуманы. Ручное значение модуля имеет приоритет над интервалом дат.

Поиск запускается в Worker и загружает зашифрованные индексы по дисциплинам, а не PDF целиком. Есть регистронезависимость, ё/е, упрощённая обработка русских окончаний, опечатка в длинном слове, точные фразы в кавычках и хештеги. Фрагменты экранируются; для PDF указывается страница. Это текстовый поиск, он не понимает математическую эквивалентность формул.

У 8 PDF отсутствует полный текстовый слой. Локальный OCR-инструмент сейчас не установлен; интерфейс показывает это ограничение. Такие страницы доступны для просмотра, но не для поиска по содержимому. Для их распознавания установите локальный OCRmyPDF/Tesseract с русской моделью, обработайте **копии** PDF в отдельной папке и выберите эту папку в панели. Не перезаписывайте Storage. Облачный OCR не используется.

## Просмотр и оригиналы

HTML открывается в `iframe sandbox="allow-scripts allow-modals"` без `allow-same-origin`. `allow-modals` разрешает системную печать и стандартные модальные диалоги браузера. В производной копии для просмотра:

- внешние KaTeX и шрифты заменяются локальными;
- мета-перенаправления, формы, вложенные фреймы и внешние ссылки удаляются;
- CSP запрещает сетевые запросы, внешние изображения и вложенные документы;
- ожидаемый лекциями localStorage заменяется временным хранилищем внутри iframe;
- широкие формулы получают локальную прокрутку.

Сам оригинальный HTML не изменяется. Скачивание HTML и PDF отдаёт исходные байты с понятным именем, сформированным по метаданным лекции. Старые HTML могут требовать интернет и соседние ресурсы; их автоматическое преобразование в автономные файлы не заявлено.

PDF.js загружается по требованию и рисует страницы по мере приближения к области просмотра. Если отображение не удалось, доступно скачивание оригинала.

Отдельная вкладка использует безопасную оболочку и одноразовый handshake, проверяя origin, окно-источник и случайный идентификатор канала. Ключ не передаётся в URL. При перезагрузке отдельной вкладки снова потребуется доступ. Выход освобождает ключи, индексы, просмотрщик и blob URL; гарантированное физическое стирание памяти JavaScript не обещается.

## Коды, отключение и восстановление

Код состоит из случайного непрозрачного ID и 256-битного секрета. PBKDF2-HMAC-SHA-256: 600000 итераций, случайная соль, время выводится в локальной панели. AES-256-GCM использует новый случайный 96-битный nonce; версия, назначение и ID аутентифицируются через AAD. Каталог, текстовые индексы, оригиналы и приватные ресурсы зашифрованы. Размер и число объектов остаются наблюдаемыми.

Код показывается только при создании. Сохраните и передайте его получателю самостоятельно. В реестре сохраняется ключ упаковки, защищённый Windows DPAPI CurrentUser. Добавление пользователя повторно использует существующие зашифрованные файлы. Отключение создаёт новую эпоху, обновляет конверты действующих пользователей без знания их паролей и перешифровывает текущую библиотеку.

**Старые ключи и скачанные материалы отозвать нельзя.** Старые зашифрованные объекты могут оставаться в кеше, открытых вкладках, копиях и истории публикаций. Внешних аккаунтов и контроля числа устройств нет. Перебор скачанного конверта возможен офлайн; длинный случайный секрет обязателен.

Чтобы перенести реестр на другой компьютер/учётную запись, используйте «Резервная копия» в панели. Копия отдельно шифруется паролем длиной минимум 16 символов. Храните пароль отдельно. Простое копирование `registry.dpapi` на другую учётную запись не заменяет резервную копию. Восстановление заменяет локальный реестр после явного подтверждения в панели.

Браузер хранит постоянно только тему, настройку движения, непрозрачные ID избранного, публичные зависимости и зашифрованные объекты. Ни ключи, ни тексты конспектов не сохраняются в localStorage или Service Worker. Кеш может быть вытеснен браузером; вечный офлайн не обещается.

## Будущая публикация

Она потребует отдельного разрешения, адреса чистого GitHub-репозитория и штатной локальной авторизации. Старую `.git` публиковать нельзя. Для Pages предусмотрены относительные URL и query-параметры без SPA fallback. Перед настоящим развёртыванием необходимо повторно проверить актуальные лимиты GitHub и прогнать проверки на выбранном `/repository/` и HTTPS. Локальные проверки не означают, что удалённый deploy уже проверен.

Технические первоисточники: [AES-GCM / MDN](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/encrypt), [PBKDF2 / MDN](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/deriveKey), [iframe sandbox / MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe).

### Текущая версия интерфейса

Предметы формируются из каталога автоматически и отличаются цветовыми метками. Названия и основной текст набраны Manrope увеличенного размера. Формулы в поисковых фрагментах отображаются локальным KaTeX; границы фрагментов не разрывают TeX-выражение.

Кнопка новой вкладки открывает `lecture.html`: только HTML-конспект на весь экран либо встроенный PDF-просмотрщик браузера, без интерфейса FAM. HTML сохраняет изоляцию sandbox. После перезагрузки этой вкладки конспект нужно открыть из библиотеки заново: расшифрованные данные остаются только в памяти.

### Просмотр и календарь

- Вложения имеют названия по роли: «Конспект · HTML» и «Материал преподавателя · PDF». Имена в каталоге и поисковом индексе не зависят от локальных имён исходных файлов. Скачивание использует название предмета, номер, тему и расширение; содержимое исходного файла сохраняется.
- В просмотрщике есть режим «PDF + конспект» с независимой прокруткой, регулировкой ширины PDF, переходом к странице, скачиванием и новой вкладкой для каждой стороны. При ширине окна до 850 px документы располагаются друг под другом. Режим доступен только при наличии обоих форматов.
- «Календарь» находится рядом с режимами списка и карточек. Цвета меток совпадают с предметами. Выбор дня показывает материалы с переходом к ним. Календарь учитывает поиск и фильтры. Материалы с несколькими датами отмечены в каждый соответствующий день; материалы без дат перечислены отдельно. Начальный месяц — текущий, если в нём есть материалы, иначе последний с датированными материалами.
- Тессеракт непрерывно вращается в 4D и 3D; движение заметно быстрее предыдущего медленного покачивания. Кнопка паузы и reduced-motion сохранены.

### Шаблон нейроконспектов

Локальный пример: **http://127.0.0.1:4173/note-template/**. Автономный HTML и инструкция для ИИ находятся в `note-template`; подробности — в `note-template/README.md`. Сборка: `node note-template/build.mjs`.

Шаблон содержит адаптивное оглавление, общие и индивидуальные режимы доказательств, ссылки с автоматическим раскрытием и печатную вёрстку PDF с тремя вариантами состава. Иллюстрации описаны через **Asymptote**, без локальной библиотеки рисунков. Указаны отдельные этапы математической и визуальной проверки ИИ. Сам Asymptote не устанавливался. Шаблон не добавляется в каталог Storage и публичный экспорт сайта.
