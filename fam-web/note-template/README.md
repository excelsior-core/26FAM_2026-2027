# Шаблон конспекта FAM

`dist/FAM-Конспект.html` — автономный файл для просмотра и передачи ИИ. Шрифты, KaTeX, оформление и интерактивность встроены; интернет не нужен. Внутри — демонстрационная лекция «Линейные отображения», без выдуманной даты и преподавателя.

Для подготовки нового конспекта передайте ИИ **этот HTML + `AI-INSTRUCTIONS.md` + материалы лекции**. Рисунки ИИ строит самостоятельно в Asymptote. Локальных заготовок иллюстраций и собственного графического движка нет. Asymptote не установлен этим шаблоном и для чтения конспекта не требуется; его запускают на этапе подготовки рисунков.

## Локальный просмотр

На запущенном сервере библиотеки: http://127.0.0.1:4173/note-template/

Также можно открыть `dist/FAM-Конспект.html` двойным щелчком в обычном браузере. Сам шаблон не добавляется в каталог лекций и не включается в публичный экспорт библиотеки.

## Доказательства и PDF

- По умолчанию открыты только идеи. Переключатели «Скрыть / Идеи / Полностью» действуют сразу на все доказательства.
- Локальные кнопки работают независимо. Переход к ссылке внутри скрытого доказательства раскрывает нужный блок.
- «Сохранить PDF» → выбрать содержание → «Перейти к печати» → «Сохранить как PDF» в браузере. Это печатная вёрстка, не снимок экрана. По умолчанию в PDF включаются идеи и полные доказательства. Ctrl+P также печатает полный текст.
- Рекомендуемые настройки браузера: A4, масштаб 100%, колонтитулы браузера выключены. Межстраничные переносы зависят от браузера: проверяйте длинные формулы и рисунки перед выдачей конкретной лекции.
- В просмотрщике FAM к sandbox добавлено только `allow-modals`, необходимое для системной печати. `allow-same-origin`, доступ к ключам и сети не добавлялись. Разрешение также позволяет документу вызывать стандартные модальные диалоги браузера.

## Правки и сборка

Из `fam-web`:

```text
node note-template/build.mjs
```

Исходники: `source.html` — содержание и оболочка; `style.css` — экран и печать; `interaction.js` — оглавление, доказательства, PDF. Сборщик встраивает существующие локальные библиотеки и лицензии, новые пакеты не нужны.

Для отдельной лекции можно передать пути явно:

```text
node note-template/build.mjs "путь/лекция.source.html" "путь/лекция.html"
```

Условия структуры и работы с формулами описаны в `AI-INSTRUCTIONS.md`. Сборщик не проверяет математические утверждения и не выполняет проверку другим ИИ: эта работа явно возлагается на ИИ, готовящий конкретную лекцию.

## Темы

Системная, светлая, тёмная и пергаментная темы выбираются в шапке. Сохраняется только выбор оформления, без текста конспекта. В изолированном просмотрщике настройка временная. Печать всегда светлая.

Новые иллюстрации имеют три встроенных варианта одной сцены Asymptote. Контракт `.themed-figure` и порядок проверки описаны в разделе 6 инструкции для ИИ. Сборка отклоняет такие рисунки, если отсутствует один из вариантов. Готовые сканы можно оставить на светлой подложке `.figure-plate`. Набора заранее созданных иллюстраций нет.
