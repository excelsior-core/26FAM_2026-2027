## 1. КОНЦЕПЦИЯ И АРХИТЕКТУРНЫЙ МАНИФЕСТ

Ты выступаешь в роли **Lead Software Architect**, **Senior Frontend Security Engineer** и **Art Director / Haute Couture Motion Designer**. Твоя цель — сгенерировать **полный, рабочий, монолитный проект под ключ**: статический веб-портал с бескомпромиссной клиентской криптографией, интерактивным академическим функционалом и полиграфическим дизайном музейного уровня.

### Ключевые постулаты:
1. **Zero-Knowledge & Zero-Leakage:** В публичном GitHub-репозитории нет открытых текстов, названий лекций, имен преподавателей, исходных PDF или HTML. В репозиторий попадают только открытая оболочка приложения и зашифрованные крипто-блобы (`.bin`).
2. **Zero-CDN (Автономность 100%):** Никаких внешних скриптов, стилей или шрифтовых ссылок (`Google Fonts`, `cdnjs`, `unpkg` строго запрещены). Все шрифты и иконки поставляются локально. Полная работоспособность офлайн через Service Worker (PWA).
3. **Единый вход с ролевым разделением:** Одно поле ввода пароля.
   * Студенческий пароль (`famlovesmath`) открывает конспекты и материалы для чтения.
   * Администраторский пароль (`excelsiorcatharsis`) открывает скрытые функции управления.
   * Админские элементы управления математически и визуально изолированы для студентов (ошибка несовпадения тега AES-GCM).
4. **Свобода чтения и абсолютный приоритет PDF (First-Class PDF Sovereignty):**
   * Оригинал рукописи преподавателя (PDF) — равноправная и первостепенная ценность наряду с HTML-конспектом.
   * Студент должен с первого взгляда видеть наличие оригинального PDF, иметь возможность открыть его в 1 клик, читать в сплит-режиме бок о бок или открывать в нативном просмотрщике.

## 3. СВЕРХВЫСОКИЙ ПРИОРИТЕТ PDF (FIRST-CLASS PDF CITIZEN)

В каждом учебном материале оригинальный рукописный PDF лектора должен быть подан как полноценный архивный экспонат:

```
                          ┌──> [ 📄 ОРИГИНАЛ РУКОПИСИ ЛЕКТОРА (PDF) ] ──> Мгновенный просмотр / Новая вкладка
                          │
[ Архивный экспонат ] ────┼──> [ 📝 НЕЙРОКОНСПЕКТ (HTML) ] ────────────> Интерактивный ридер с формулами
                          │
                          ├──> [ ⚖️ СПЛИТ-РИДЕР (SIDE-BY-SIDE) ] ──────> Конспект слева + PDF рукописи справа
                          │
                          └──> [ 💾 СКАЧАТЬ ] ─────────────────────────> Раздельно с красивыми русскими именами
```

1. **Явная визуальная индикация PDF:**
   * На каждом экспонате/карточке должен быть четкий, роскошный блок рукописи: золоченый бейдж `📄 РУКОПИСЬ ЛЕКТОРА (PDF)`, количество страниц/размер или прямой предпросмотр.
   * Студент должен иметь возможность открыть чистый PDF оригинальной рукописи лектора в 1 клик без необходимости открывать конспект HTML.
2. **Мобильная безупречность:**
   * На iOS / Safari рукописи открываются через нативный `blob:URL` в новой вкладке для устранения дефектов мобильного iframe.
3. **Сплит-ридер (Side-by-Side):**
   * Интерактивный сплит-просмотр: левая половина экрана — синтезированный HTML-конспект с поддержкой KaTeX, правая — полноразмерная рукопись лектора с перемещаемым разделителем.

## 5. КРИПТОГРАФИЯ И АРХИТЕКТУРА БЕЗОПАСНОСТИ (ZERO-KNOWLEDGE)

```
[ Локальные файлы Storage ] ──> [ sync.js (GZIP + AES-256-GCM) ] ──> [ blobs/*.bin + metadata.bin + admin.bin ]
                                                                                   │
[ Браузер клиента ] <── [ PBKDF2 (600k) ──> Master AES-GCM Key ] <─────────────────┘
```

1. **Стандарты шифрования:**
   * **KDF:** PBKDF2-HMAC-SHA256, **600 000 итераций**.
   * **Шифр:** `AES-GCM` 256 бит, 12-байтный случайный IV на каждый файл.
   * **Сжатие:** `GZIP` (`CompressionStream`) перед шифрованием.
   * **Формат блоба (`.bin`):** `FAMB1` (5 байт) + `0x01` (версия) + Соль KDF (16 байт) + IV (12 байт) + Шифртекст с аутентификационным тегом GCM (16 байт).
2. **Архитектура единой соли (Vault Salt):**
   * Единая мастер-соль хранилища вычисляется 1 раз при вводе пароля, после чего сотни лекций и PDF расшифровываются мгновенно (<1 мс на файл).
3. **Разделение ролей и ключей:**
   * Студенческий пароль (`famlovesmath`): расшифровывает `metadata.bin`. При попытке открыть `admin.bin` WebCrypto выбрасывает криптографическую ошибку несовпадения тега GCM → роль администратора строго заблокирована.
   * Админ-пароль (`excelsiorcatharsis`): расшифровывает `admin.bin`, откуда извлекается `sharedKeyHex` для сквозного доступа ко всем материалам и элементам управления.
   * Пароли задаются в `scripts/sync.json` (в `.gitignore`) и могут быть мгновенно изменены.

## 6. МОДЕЛЬ ДАННЫХ И ФАЙЛОВАЯ СИСТЕМА STORAGE (ДИНАМИЧЕСКИЙ MIRROR-MODE)

Любые изменения производятся простым созданием и удалением папок:

```
HSE-STORAGE/
├── Storage/
│   └── HSE/
│       ├── site-metadata.json           <-- Экспортируемый конфиг
│       ├── Матанализ/
│       │   ├── лекции/
│       │   │   └── 01 02.09.2026 Введение в анализ/
│       │   │       ├── conspect.html    <-- Нейроконспект
│       │   │       └── оригинал/        <-- Рукопись лектора
│       │   │           └── lecture_01.pdf
│       │   ├── коллоквиумы/
│       │   │   └── 01 20.10.2026 Вопросы к 1 коллоквиуму/
│       │   │       └── conspect.html
│       │   └── экзамены/...
│       ├── Линал и Аналит/...
│       ├── Дискретная математика/...
│       └── <Любой новый предмет>/       <-- Оживает автоматически!
├── scripts/
│   ├── sync.js                          <-- Движок синхронизации и шифрования
│   ├── sync.json                        <-- Конфиг паролей (.gitignore)
│   ├── watch.js                         <-- Автосинхронизатор с дебаунсом 2 сек
│   └── serve.js                         <-- Локальный zero-dependency веб-сервер
├── blobs/                               <-- Зашифрованные bin-файлы для GitHub
├── metadata.bin                         <-- Зашифрованный каталог студентов
├── admin.bin                            <-- Зашифрованный каталог админа
├── manifest.json                        <-- Реестр размеров блобов
├── start.bat, sync.bat, watch.bat       <-- ASCII Windows-раннеры
└── index.html, styles/, app/, fonts/    <-- Исходный код витрины
```

### Правила обработки:
1. **Auto-Chroma:** Любой новый предмет автоматически получает благородный королевский оттенок и оформление.
2. **Категоризация:** Автоматическое разделение по папкам внутри предмета: `лекции`, `коллоквиумы`, `экзамены`, `семинары`.
3. **Умный парсер дат и пар:** Названия папок вида `05 18.09.2026 Пределы` парсят номера занятий, даты и очищают заголовок.
4. **Истинный Mirror-Mode:** Удаление папки материала локально удаляет блобы с сайта и очищает метаданные.

## 8. ИНФРАСТРУКТУРА, ДЕПЛОЙ И WINDOWS RUNNERS

1. **Развертывание на GitHub Pages (`gh-pages`):**
   * Скрипт `scripts/sync.js` собирает `.gh-dist` и выполняет **orphan force-push** в ветку `gh-pages` (история больших бинарных файлов не накапливается).
2. **ASCII Windows Runners:**
   * `.bat` файлы (`start.bat`, `sync.bat`, `watch.bat`) написаны на чистом ASCII без сбоев `cmd.exe` и автоматически находят Node.js в `PATH` или локальных путях.
3. **Фоновый автосинхронизатор (`watch.bat`):**
   * Отслеживает изменения в `Storage/` с дебаунсом 2 секунды.
