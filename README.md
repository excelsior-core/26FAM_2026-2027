# FAM / FUNDAMENTAL & APPLIED MATH
### Академическая библиотека и лекционные конспекты ФПМ НИУ ВШЭ (Нижний Новгород)

Неофициальный студенческий проект студентов факультета «Фундаментальная и прикладная математика» НИУ ВШЭ — Нижний Новгород.

## 🔑 Код доступа к библиотеке

Все материалы сайта и лекции защищены сквозным клиентским шифрованием (AES-256-GCM + PBKDF2-HMAC-SHA-256). Для входа в библиотеку используйте код:

```text
FAM.5d757fdd806e94f1936ba5b79a73e4c4.vg796Kxqxy5tNO2MQ-lSNgktWOH6v_Q3uvjwgvYzG9k
```

> **Примечание:** При локальном запуске на компьютере владельца вводить код не обязательно — достаточно нажать кнопку **«Вход владельца · локальный просмотр»**.

## 🚀 Быстрый запуск на Windows

Все основные действия запускаются готовыми `.bat` файлами в один клик:

1. **`start-local.bat`** — Запуск локального сервера библиотеки.  
   Открывает сайт в браузере: **http://127.0.0.1:4173/**.  
   Доступен просмотр всех лекций, поиск, переключение тем и 3D-тессеракт.

2. **`start-admin.bat`** — Панель управления библиотекой.  
   Открывает админку: **http://127.0.0.1:4173/admin**.  
   Здесь можно:
   - Сканировать новые материалы в `Storage/`;
   - Выпускать персональные коды доступа для студентов;
   - Настраивать модули и метаданные;
   - Пересобирать зашифрованную библиотеку;
   - Делать резервные копии реестра.

3. **`publish.bat`** — Публикация на GitHub и GitHub Pages.  
   Автоматически:
   - Пересобирает зашифрованный экспорт;
   - Публикует статический сайт в ветку `gh-pages`;
   - Синхронизирует исходники в ветку `main`.

4. **`watch.bat`** — Режим авто-наблюдения за папкой `Storage/`.  
   Автоматически пересобирает локальную библиотеку при изменении файлов.

## 📝 Как устроен шаблон конспектов (`fam-web/note-template`)

Все 32 лекции библиотеки переведены на этот шаблон:
- **Полная автономность (Zero-CDN):** В каждый HTML-файл встроены шрифты *Manrope* и *Cormorant Garamond*, движок формул *KaTeX* и стили. Файл работает без интернета.
- **Интерактивные доказательства:**
  - Общий переключатель: «Скрыть» / «Идеи» / «Полностью»;
  - Индивидуальные кнопки на каждом доказательстве;
  - Ссылки на теоремы автоматически раскрывают скрытый блок.
- **Три темы оформления:** Светлая, Тёмная и Пергаментная.
- **Идеальная печать в PDF:** Режим «Сохранить PDF» формирует чистую книгу без артефактов браузера и с правильными разрывами страниц.
