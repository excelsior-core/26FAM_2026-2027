## 💎 Визуальный манифест и киллер-фичи

1. **Музейная экспозиция Лувра (Haute Couture Editorial Spread):**
   * **Никакого типового SaaS:** Шаблонные прямоугольные карточки и синусоидальные волны полностью устранены.
   * **Монументальный Hero Folio:** Актуальный экспонат недели оформлен как центральное полотно в резной золоченой раме с акантовым орнаментом, драматичной верхней светотенью Караваджо и прямым доступом к рукописи лектора.
   * **Асимметричные диптихи:** Чередование фолиантов с чертежными осями, циркульными дугами и водяной типографикой (`STATUES`, `MATHEMATICA`, `ANALYSIS`).
   * **Режим архивного реестра:** Возможность в один клик переключиться на плотный табличный вид с алмазными маркерами (`❖`, `✦`) для сессионной подготовки.

2. **Абсолютный приоритет PDF (First-Class PDF Sovereignty):**
   * Оригинал рукописи лектора подается как главная непреходящая ценность архива.
   * **1-клик доступ:** Рукопись открывается сразу без обязательного открытия HTML-конспекта.
   * **Сплит-ридер (Side-by-Side):** Конспект слева + полноразмерный оригинальный PDF справа с интерактивным перетаскиваемым разделителем.
   * **Мобильный segmented-switch:** На смартфонах мгновенный таб-переключатель (`[ 📝 Конспект ]` / `[ 📄 Рукопись ]`) + нативное открытие через `blob:URL` в новой вкладке Safari.
   * **Культура скачивания:** Автоматическая генерация благородных русских имен:  
     `[ФПМ ВШЭ] Матанализ · Лекция 01 · Введение в анализ (Оригинал).pdf`.

3. **Мистический 3D Vault Gate:**
   * По центру экрана авторизации из полумрака материализуется процедурный 3D-артефакт познания:
     * 🪐 **Астролябия Познания** — парящая армиллярная сфера с золочеными кольцами.
     * 🧊 **4D Тессеракт** — стереографическая проекция вращающегося 4D-гиперкуба.
     * 🗝️ **Криптекс Ордена** — древний цилиндрический замок с кольцами математических символов ($\nabla, \int, \oint, \partial, \infty, \mathbb{R}$), физически реагирующий на ввод символов пароля.
   * Парящая золотая библиотечная пыль, инерция мыши и нулевое потребление CPU/GPU после авторизации.

4. **Личные зашифрованные маргиналии (Encrypted Marginalia):**
   * Выделение текста в конспекте 3 музейными маркерами (🟡 Золотой пергамент, 🔴 Охра, 🔵 Мыслитель) + добавление заметок на полях.
   * Все пометки шифруются мастер-ключом студента и сохраняются локально в браузере.

5. **Суточное освещение (Chiaroscuro Time-Lapse):**
   * Температура интерфейса плавно следует за временем суток в Москве:
     * *Рассветный архив (05:00–10:00)*: холодный серебристый туман.
     * *Дневной зал (10:00–17:00)*: теплый музейный пергамент.
     * *Сумеречная ложа (17:00–22:00)*: медно-янтарный закат.
     * *Ночной бархат (22:00–05:00)*: глубокий обсидиановый полумрак.

6. **Режим конспирации (Panic Key — двойной `Esc`):**
   * Быстрое двойное нажатие `Escape` мгновенно стирает сессионные и долговременные ключи из памяти браузера, заливает экран обсидиановым блэкаутом и блокирует портал.

## 🔒 Безопасность и Zero-Knowledge архитектура

```
[ Локальные файлы Storage ] ──> [ sync.js (GZIP + AES-256-GCM) ] ──> [ blobs/*.bin + metadata.bin + admin.bin ]
                                                                                   │
[ Браузер клиента ] <── [ PBKDF2 (600k) ──> Master AES-GCM Key ] <─────────────────┘
```

1. **Zero-Knowledge & Zero-Leakage:** В публичном GitHub-репозитории нет открытых текстов, названий лекций, имен преподавателей, исходных PDF или HTML. В репозиторий попадают только открытая оболочка приложения и зашифрованные крипто-блобы (`.bin`).
2. **Zero-CDN (Автономность 100%):** Никаких внешних ссылок (`Google Fonts`, `cdnjs`, `unpkg` запрещены). Все шрифты (`Cormorant Garamond`, `Unbounded`, `Golos Text`) и скрипты поставляются локально. Полная оффлайн-работоспособность через Service Worker (PWA).
3. **Разделение ролей:**
   * Студенческий пароль (`famlovesmath`): открывает конспекты и материалы для чтения. Попытка открыть `admin.bin` приводит к криптографической ошибке аутентификационного тега AES-GCM → элементы админки физически заблокированы.
   * Администраторский пароль (`excelsiorcatharsis`): дешифрует `admin.bin`, откуда извлекается `sharedKeyHex` для сквозного доступа ко всем материалам и панели управления.

## 🚀 Запуск через Windows Runners (.bat)

В корне подготовлены 3 ASCII-батника с автопоиском Node.js в системе (PATH, Strata, Program Files):

1. **`start.bat`** — запуск автономного локального веб-сервера и автоматическое открытие в браузере: `http://localhost:3000`.
2. **`sync.bat`** — сканирование `Storage/HSE/`, шифрование (GZIP + AES-256-GCM), зеркалирование blobs и деплой на GitHub Pages.
3. **`watch.bat`** — фоновый страж: автоматическая пересборка с дебаунсом 2 секунды при сохранении любого файла в `Storage/`.

* `Ctrl + K` или `/` — интеллектуальная командная палитра и сниппет-поиск.
* `Esc × 2` (двойное нажатие) — режим конспирации (Panic Key), мгновенный сброс сессии и блокировка.
