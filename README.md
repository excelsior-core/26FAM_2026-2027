# «“конспекты” ФПМ»

> **Студенческий сборник нейроконспектов · ФПМ НН · 1 курс (2026–2027)**  
> Статический веб-сайт на GitHub Pages с клиентским шифрованием **AES-256-GCM**, админ-панелью, поиском Ctrl+K, Split-View и автоматической синхронизацией.

---

## 🔒 Безопасность и Архитектура

1. **Client-Side Encryption:** Все конспекты и оригиналы лекций перед загрузкой в git сжимаются через gzip и шифруются **AES-256-GCM** с формированием ключа через **PBKDF2-SHA256 (600 000 итераций)**.
2. **Нулевая утечка в Git:** В репозитории GitHub (`gh-pages`) хранятся **только зашифрованные blobs** (`blobs/<hash>.bin`), открытый `manifest.json` (размеры файлов без названий) и оболочка сайта. Ни названий предметов, ни фамилий преподавателей, ни текстов лекций в открытом виде на сервере нет.
3. **Единое окно входа (Умная авторизация):**
   * Студент вводит общий пароль курса → расшифровывается `metadata.bin`, сайт открывается в обычном режиме для чтения.
   * Вы вводите мастер-пароль админа → расшифровывается `admin.bin`, на сайте бесшовно активируется **Режим управления** (редактирование модулей, предметов, тегов, пар и экспорт `site-metadata.json`).
4. **100% автономность:** Никаких внешних CDN, Google Analytics или сторонних скриптов. Полный оффлайн-доступ через Service Worker.

## 🚀 Быстрый старт

### 1. Настройка паролей и репозитория
При первом запуске создается файл `scripts/sync.json`. Откройте его и укажите ваши пароли и URL репозитория на GitHub:
```json
{
  "storagePath": "./Storage",
  "repoUrl": "https://github.com/ВАШ_АККАУНТ/FAM_2026-2027_HSE.git",
  "sharedPassword": "fpm2026",
  "adminPassword": "admin2026",
  "branchDeploy": "gh-pages",
  "branchSource": "main"
}
```

По умолчанию уже установлены пароли:
* **Для студентов:** `fpm2026`
* **Для администратора:** `admin2026`

### 2. Локальный запуск сайта на ноутбуке
Браузеры блокируют дешифрование при открытии напрямую через `file://`.
Просто дважды кликните:
```cmd
start.bat
```
Скрипт мгновенно запустит локальный веб-сервер и откроет сайт в браузере по адресу `http://localhost:3000`.
Запустите PowerShell-скрипт (если шрифты не скачивать, сайт автоматически применит красивый системный типографический стек):
```powershell
powershell -ExecutionPolicy Bypass -File fonts/download.ps1
```

### 3. Синхронизация и публикация на GitHub
Просто запустите двойным кликом:
```cmd
sync.bat
```
Скрипт автоматически:
1. Просканирует папку `Storage/HSE/`.
2. Сожмет HTML-конспекты и PDF-оригиналы в GZIP.
3. Зашифрует их через AES-256-GCM в папку `blobs/`.
4. Сформирует и зашифрует `metadata.bin` и `admin.bin`.
5. Опубликует чистую витрину в ветку `gh-pages` на GitHub Pages через orphan force-push.

### 4. Режим автосинхронизации (Watch)
Когда вы добавляете новые конспекты в папку `Storage`, запустите:
```cmd
watch.bat
```
При любом сохранении файлов скрипт подождет 2 секунды и автоматически обновит шифрованные blobs!

## 🌐 Настройка GitHub Pages

1. Создайте пустой репозиторий на GitHub (например, `FAM_2026-2027_HSE`).
2. Вставьте его адрес в `scripts/sync.json`.
3. Запустите `sync.bat`.
4. В настройках репозитория на GitHub:
   * **Settings → Pages**
   * **Build and deployment → Source:** выберите `Deploy from a branch`
   * **Branch:** выберите `gh-pages` и папку `/ (root)`. Нажмите **Save**.
5. Через 1–2 минуты сайт станет доступен по адресу:
   `https://ВАШ_АККАУНТ.github.io/FAM_2026-2027_HSE/`

## ✨ Фичи для студентов и гиков

* **Split-View «Конспект ↔ Оригинал»:** В модалке чтения на широком экране нажмите кнопку *«⇄ Оригинал рядом»* — слева откроется чистый HTML нейроконспекта, а справа оригинальный PDF лектора для мгновенной сверки формул.
* **Чек-лист подготовки:** Кнопка *«Отметить изученным»* на карточке лекции сохраняет ваш личный прогресс в браузере. Фильтр *«Неразобранные»* мгновенно оставляет только то, что ещё предстоит выучить.
* **Полнотекстовый поиск (`Ctrl+K` или `/`):** Ищет по заголовкам, датам, номерам пар и даже внутри расшифрованных HTML-конспектов со сниппетами и подсветкой совпадений.
* **Горячие клавиши:**
  * `Ctrl+K` или `/` — открыть командную строку поиска
  * `T` — переключить цветовую тему (Бумага → Тёмная → Сепия → Полночь)
  * `Esc` — закрыть окно чтения или поиска
* **Ротация паролей через консоль:**
  * `node scripts/sync.js --rotate-shared новый_пароль`
  * `node scripts/sync.js --rotate-admin новый_пароль`
